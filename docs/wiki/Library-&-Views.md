# Library & Views

## Platforms Screen
- **Apple TV-style Hero Showcase** with platform logo, release year, manufacturer, ROM count, and dynamic blurred background.
- **Alphabetical Sorting** by platform display name (e.g., *Commodore Amiga* under `C`).
- **Collections**: **Recently Played** and **Downloaded** appear first for quick access.
- **Global Search (`S`)**: Search across all 170+ platforms and browse matching games grouped by platform.

## Game Library Views
Press **`V`** (or use the top-right toggle) to switch between 3 views. Your last selected view is **persisted automatically** across restarts:
1. **List View**: Clean game list on the left (`44%`) + rich detail panel on the right (`56%`) with media carousel, description, metadata, and **Play** button.
2. **Carousel View**: Full-width showcase + horizontal bottom cover rail (supports keyboard arrows and mouse wheel).
3. **Grid View**: Responsive box-art grid.

In **Recently Played**, **Downloaded**, and **Global Search**, games are automatically **grouped by platform** with section headers and platform badges.
