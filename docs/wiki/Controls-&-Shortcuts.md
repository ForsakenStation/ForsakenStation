# Controls & Shortcuts

Every full screen displays available keyboard and gamepad bindings in the `ControlsBottomBar` at the bottom.

## Keyboard Shortcuts

| Screen | Key | Action |
|---|---|---|
| **Global** | `Esc` / `Backspace` | Back / Exit confirmation |
| **Global** | `Tab` | Open Settings |
| **Global** | `F1` / `?` | Open Controls Help |
| **Platforms** | `←` / `→` | Previous / Next platform |
| **Platforms** | `Shift + A–Z` | Jump to platform by initial |
| **Platforms** | `S` | Global game search |
| **Platforms** | `R` | Refresh platforms |
| **Platforms** | `Enter` | Open selected platform |
| **ROMs** | `↑` `↓` `←` `→` | Navigate games |
| **ROMs** | `Shift + A–Z` | Jump to game by initial |
| **ROMs** | `V` | Cycle view (List / Carousel / Grid) |
| **ROMs** | `S` | Filter current game list |
| **ROMs** | `M` | Open media / manual viewer |
| **ROMs** | `Q` / `E` | Previous / Next platform |
| **ROMs** | `Enter` | Launch selected game |

## Gamepad Controls
- **D-Pad / Left Stick**: Navigate
- **A**: Select / Launch
- **B**: Back
- **X / Y / Start**: Context actions shown in the bottom bar (Refresh, Search, Toggle View, Settings)
- Test your controller anytime in **Settings → Gamepad Test**.
