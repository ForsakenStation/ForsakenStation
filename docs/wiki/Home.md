# Welcome to the Forsaken Wiki

**Forsaken** is a modern, cross-platform retro gaming frontend built with Flutter. It supports **170+ platforms**, keyboard and gamepad navigation, EmulationStation `gamelist.xml` metadata/media, and built-in emulator, BIOS, and ROM storage management.
