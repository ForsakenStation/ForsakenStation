# Controles y Atajos

Todas las pantallas muestran los controles disponibles en la barra inferior (`ControlsBottomBar`), adaptándose automáticamente si hay un mando conectado.

## Atajos de Teclado

| Pantalla | Tecla | Acción |
|---|---|---|
| **Global** | `Esc` / `Backspace` | Atrás / Confirmar salida |
| **Global** | `Tab` | Abrir Ajustes |
| **Global** | `F1` / `?` | Ayuda de controles |
| **Plataformas** | `←` / `→` | Plataforma anterior / siguiente |
| **Plataformas** | `Shift + A–Z` | Saltar a plataforma por inicial |
| **Plataformas** | `S` | Buscador global de juegos |
| **Plataformas** | `R` | Actualizar plataformas |
| **Plataformas** | `Enter` | Entrar en la plataforma |
| **ROMs** | `↑` `↓` `←` `→` | Navegar por los juegos |
| **ROMs** | `Shift + A–Z` | Saltar a juego por inicial |
| **ROMs** | `V` | Cambiar vista (Lista / Carrusel / Grid) |
| **ROMs** | `S` | Filtrar listado actual |
| **ROMs** | `M` | Visor de medios / manuales PDF |
| **ROMs** | `Q` / `E` | Plataforma anterior / siguiente |
| **ROMs** | `Enter` | Lanzar juego seleccionado |

## Mando / Gamepad
- **Cruceta / Stick izquierdo**: Navegar
- **A**: Seleccionar / Jugar
- **B**: Atrás
- **X / Y / Start**: Acciones contextuales mostradas en la barra inferior
- Puedes probar tu mando en **Ajustes → Test de Gamepad**.
