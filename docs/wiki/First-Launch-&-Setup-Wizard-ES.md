# Primer Inicio y Asistente de Configuración

Al abrir Forsaken por primera vez, el **Asistente de Configuración** te guía en tres pasos:

1. **Aceptación del Aviso Legal** — Confirma que Forsaken es solo un frontend y no incluye ROMs ni BIOS con derechos de autor.
2. **Rutas del Sistema** — Configura los directorios por defecto (guardados en `SharedPreferences` y editables en **Ajustes → Rutas del Sistema**):
   - `MEDIA_PATH`: Carátulas, capturas, vídeos y manuales PDF.
   - `EMULATORS_PATH`: Binarios de emuladores (`.AppImage`, `.exe`, `.app`).
   - `EMULATORS_CONFIG_PATH`: Overrides locales de `config.json`.
   - `ROM_TEMP_PATH`: Carpeta temporal para ROMs que se limpian tras jugar.
   - `ROM_FOREVER_PATH`: Carpeta permanente para ROMs guardadas o extraídas.
3. **Base de Datos y Gamelists** — Puedes descargar listas de ROMs y metadatos `gamelist.xml` en cualquier momento desde **Ajustes → Base de Datos de ROMs**.
