# First Launch & Setup Wizard

When you launch Forsaken for the first time, the **Setup Wizard** guides you through:

1. **Legal Disclaimer Acceptance** — Confirms that Forsaken is a frontend only and does not include copyrighted ROMs or BIOS files.
2. **System Paths Configuration** — Sets default directories (stored in `SharedPreferences`, editable later in **Settings → System Paths**):
   - `MEDIA_PATH`: Box art, screenshots, videos, and PDF manuals.
   - `EMULATORS_PATH`: Emulator binaries (e.g. `.AppImage`, `.exe`, `.app`).
   - `EMULATORS_CONFIG_PATH`: Custom `config.json` overrides.
   - `ROM_TEMP_PATH`: Temporary folder for downloaded ROMs deleted after play.
   - `ROM_FOREVER_PATH`: Permanent folder for saved or extracted ROMs.
3. **ROM Database & Gamelists** — Optionally download the community ROM lists and `gamelist.xml` metadata from **Settings → ROM Database** at any time.
